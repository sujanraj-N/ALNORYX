GITHUB PAGES INSTALL
1. Extract this ZIP on your computer.
2. Open your ALNORYX repository on GitHub and choose Add file > Upload files.
3. Upload index.html, manifest.webmanifest, and sw.js. Upload the icons folder with both PNGs inside it. Do not upload the ZIP itself.
4. Commit changes to the main branch.
5. Wait for GitHub Pages to publish, then open your site over HTTPS. In Chrome, use Install app or Add to Home screen.

SECURITY NOTE
The current app is a frontend prototype. Shared accounts, protected admin tools, subscriptions, real payments, secure file storage, and cross-device data require a backend and proper authentication/authorization. GitHub Pages alone cannot provide these securely. Revenue is not guaranteed.
